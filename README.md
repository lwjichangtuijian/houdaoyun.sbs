# 厚道云 (Houdaoyun) 官方推广落地页

厚道云官方专线网络加速推广落地页与 SEO 知识科普站，采用纯 HTML5 与原生极简 CSS 构建，达到秒开级加载性能与高转化率视觉设计。

## 核心特性

- **极简高性能**：无任何外部重型 JS 框架或第三方字体库，首屏秒开。
- **深海蓝 × 冰川青视觉体系**：
  - 深海蓝（导航 / Hero / 页脚）：`#142C3E`
  - 层次蓝（深色卡片 / 辅助背景）：`#244E60`
  - 冰川青（主按钮 / 高亮交互）：`#25B7B8`
  - 浅冰青（内容区域交替背景）：`#E9F4F4`
  - 纯白（卡片 / 交替背景）：`#FFFFFF`
- **Hero 精密激光扫描特效**：纯 CSS Transform/Opacity 硬件加速渲染，白青色高亮核心线与网格数据唤醒拖尾。
- **全站 SEO 与结构化数据**：
  - 包含 `sitemap.xml`（15 个核心 URL）与 `robots.txt`
  - 完善的 TDK、Open Graph 社交分享卡片与 Schema.org `Product` 结构化数据
  - 9 篇 SEO 深度技术科普文章与默认展开 FAQ
- **IndexNow 接入**：内置 PowerShell、BAT 及 Python 自动化 URL 推送工具包。

## 目录结构

```
├── index.html                  # 官网推广主落地页
├── style.css                   # 原生 CSS 样式表（含响应式与动画）
├── knowledge.html              # 知识科普专栏入口
├── article-1.html ~ 9.html     # 9 篇专线技术与机场推荐科普文章
├── about.html                  # 关于我们
├── terms.html                  # 服务条款
├── privacy.html                # 隐私政策 (Zero-Logs)
├── sitemap.html                # HTML 网站地图
├── sitemap.xml                 # XML 站点地图
├── robots.txt                  # 搜索引擎爬虫协议
├── favicon.svg / png           # 全套高分屏 Favicon 图标
├── logo.svg / png              # 高清品牌矢量与位图 Logo
├── og-image.png / svg          # 社交媒体预览图
└── indexnow_scripts/           # IndexNow API 提交脚本工具包
```
